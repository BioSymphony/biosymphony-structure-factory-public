# Orchestration Fixtures

Compact JSON fixtures for advanced Structure Factory orchestration patterns: active learning, screening shards, scientific memory, validation graphs, receptor-state registries, and design tranche planning.

The provider-run fixtures cover FAL serverless, Modal functions, and Lambda Cloud
VM vocabulary as planned synthetic records. They contain no provider run IDs,
credentials, account references, or readiness claims.

## Use It For

- schema and adapter examples without real provider runs
- agent planning around screening and design fanout
- public validation-graph and active-learning demonstrations
- fixture inputs for `make screening-schema-check`

## Hand A Mission To An Agent

```text
Use the BioSymphony Structure Factory skill. Review examples/orchestration-fixtures as public orchestration fixtures. Explain what each fixture demonstrates, keep every output at public_synthetic_demo or planning level, and treat the JSON files as contract shape rather than real biological results.
```

## Run It Yourself

```bash
make screening-schema-check
bsf audit .
```

The files in this folder are contract examples. Store screening output, generated candidate sequences, private biological data, provider logs, and model weights under ignored runtime storage or in a user-selected artifact store.
